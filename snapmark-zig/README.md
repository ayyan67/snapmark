# SnapMark Zig

Native macOS benchmark-first rewrite of SnapMark.

## Toolchain

- Zig `0.15.2`
- macOS command line tools (`xcode-select --install`)

On macOS 26, Zig 0.15.2 fails to link against the macOS 26 SDK, so `zig build` does
not work there yet. The top-level README has a `zig build-exe` command that builds
against a macOS 15 SDK instead.

## Commands

```bash
zig build run      # Launch app
zig build release  # Create .app in zig-out/
zig build dmg      # Create DMG in zig-out/
zig build bench    # Run startup/RSS/CPU benchmark harness
zig build acceptance # Generate side-by-side acceptance report
```

## Current Scope (Phase 6 Packaging + Rollout)

- Native AppKit window + custom canvas view
- Shape union model with monotonic `u64` IDs
- Drawing tools: `pen`, `circle`, `rect`, `arrow`, `line`, `text` (default text placement)
- Shift constraints for circle/rect while dragging
- Native clipboard paste as background image (`Cmd+V`)
- Native clipboard copy from rendered canvas (`Cmd+C`)
- Native inline text overlay (`NSTextField`) with Enter/blur commit and Escape cancel
- Select tool hit-testing + selection bounds and resize handles
- Move and resize selected shapes with history write-on-change
- Undo/redo + history cap/dedup (`Cmd/Ctrl+Z`, `Cmd/Ctrl+Shift+Z`)
- Delete selected shape (or last shape fallback) via `Backspace`/`Delete`
- Tool key mapping `1..7`
- Native top toolbar with shortcut-labeled tool buttons plus color/stroke controls
- Menu bar tray item to show window and paste clipboard
- Global hotkey `Cmd+Shift+A` to show window and paste clipboard
- Hide window on `Esc`
- Signed `.app` generated by release script (ad-hoc by default, identity override supported)
- DMG packaging from Zig pipeline
- Side-by-side acceptance report/checklist in `zig-out/acceptance-report.md`

This directory is intentionally parallel to the existing Tauri app while parity work continues.

## Signing

- Default signing is ad-hoc (`SNAPMARK_CODESIGN_IDENTITY=-`) for local distribution/testing.
- To use a Developer ID certificate:
  - `export SNAPMARK_CODESIGN_IDENTITY="Developer ID Application: <Your Name> (<TeamID>)"`
  - Optional entitlements: `export SNAPMARK_CODESIGN_ENTITLEMENTS="/absolute/path/to/entitlements.plist"`
  - Run `zig build release` (or `zig build dmg`)
